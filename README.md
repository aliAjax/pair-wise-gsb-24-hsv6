# hxwl-10 考古探方记录台

遗址探方、地层关系与出土物坐标档案（离线可用）

## 技术栈

React + Vite + TypeScript + CSS，本地档案基于 localStorage

## 本地运行

```bash
npm install
npm run dev
```

开发端口：5110

## 功能

- **离线记录台**：新增、编辑、作废探方记录，全部数据写入本地档案（localStorage），刷新后自动恢复
- **入库校验**（任一冲突整体拒绝，保留未提交内容并指向对应字段）：
  - 同一探方内坐标点必须唯一
  - 深度不得逆行地层顺序（同探方内层位越深、深度应越大）
  - 出土物只能关联有效（存在且未作废）的遗迹单位
  - 被关联的遗迹单位不得作废、不得改号
  - 非法记录不会写入本地档案
- **作废与撤销**：最近一次作废持久保存，刷新后仍可一键撤销；撤销前重新校验，避免把冲突带回档案
- **实时看板**：随筛选（灰坑 / 墓葬 / 房址 / 沟状遗迹）重算探方数、地层数、出土物、未整理记录，并列出跨层异常与空关联明细
- **导出摘要**：当前筛选下的记录与看板统计导出为 JSON

## 数据说明

- 初始样本档案含一组跨层异常（T0204 第2层 1.2m 与第3层 0.8m 倒置）与两条空关联，便于查看看板效果
- 清除浏览器 localStorage 中 `hxwl10.*` 键即可重置档案
